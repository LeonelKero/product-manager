# Alshadows Tech - Product Manager API

This a Spring Boot application for managing products. It is made using following technologies.

## Tech Stack

- Java 17
- Spring Boot 3.4.1
- Spring Boot Starter Web
- Spring Boot Starter Data JPA
- H2 (dev only)
- Lombok
- Spring Boot Devtools (dev only)
- Apache Common lang3
- Spring Boot Starter Test
- Spring Starter Security

## Features

- Full CRUD operations on Product entity
